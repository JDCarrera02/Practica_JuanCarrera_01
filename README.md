# Practica_JuanCarrera_01
Entregable de la practica App

### Distribucion de la aplicacion
La aplicacion cuenta con las siguientes interfaces:
	- Login
	- DashBoard
	- Edad canina
	- Super heroes
	- Detalles super heroes
	
### Uso
	- Clonar el repositorio y abrirlo en Android Studio.
* En el caso que se descargue en .zip, descomprimir y abrir la carpeta en Android Studio

	- Ejecutar el fichero LoginActivity.kt, que se encuentra en app/src/main/java/org/iesch/appPractica
* Utilizar cable de datos para ver el resultado en el dispositivo android, en el caso contrario, instalar un emulador de dispositivo en el proyecto.
